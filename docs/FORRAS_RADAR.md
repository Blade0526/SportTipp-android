# Forrás Radar v0.1

Kezdeti jelöltek:
- Forebet
- PredictZ
- WinDrawWin
- TotalCorner
- további nyilvános, regisztráció nélkül használható források

Minden adapter előtt ellenőrizendő:
1. nyilvánosan elérhető-e;
2. kell-e regisztráció;
3. automatizált lekérés összeegyeztethető-e az oldal feltételeivel;
4. milyen piacokat ad;
5. vannak-e történelmi eredményei;
6. mennyire strukturált/stabil az oldal;
7. független-e más forrásoktól.

A v0.1 nem állítja a demonstrációs adatokat élő internetes tippeknek.
